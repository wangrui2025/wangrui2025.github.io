# Academic gateway Dev

This public folder explains how the redirect gateway is maintained. Shared lifecycle rules are in the [Dev folder protocol](https://github.com/mykcs/.codex/blob/main/engineering/DEV_PROTOCOL.md).

- [LATEST.md](LATEST.md): current development direction and provider roles.
- [DESIGN.md](DESIGN.md): why the small validation and hosting design fits this gateway.
- [ARCHIVE.md](ARCHIVE.md): replaced directions, when they exist.

[`AGENTS.md`](../../AGENTS.md) and [`README.md`](../../README.md) describe the current gateway boundary. The tracked redirect HTML files and live [GitHub Pages settings](https://github.com/wangrui2025/wangrui2025.github.io/settings/pages) own actual behavior and publication. The [Wish](../wish/README.md) owns product intent. [PR #3](https://github.com/wangrui2025/wangrui2025.github.io/pull/3) proposes a future redirect-integrity CI gate; its plan does not make that gate current.
