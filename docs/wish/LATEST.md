# 当前愿望

更新：2026-09-23

> **我希望 `wangrui2025.github.io` 永远是一个可靠、轻量的学术旧入口：别人从论文、GitHub Profile、简历或旧收藏打开它时，会直接到当前正式主页；它自己不复制完整主页、不保存私人开发源码，也不制造第二份需要维护的网站。**

优先保护三件事：

- **旧学术链接长期有效。** 已经传播出去的 `wangrui2025.github.io` 不因为主页换托管商而失效。
- **直接到正式站。** 兼容入口直接指向当前 canonical serving host，不经过另一个兼容网关。
- **只做网关。** 这里可以公开，因为它只保存必要的跳转壳、说明和治理文件；完整主页源码继续留在私人开发仓库。

这个仓库不应该重新长成一份完整主页，也不应该成为 `mykcs` 私人开发仓库的公开镜像。
