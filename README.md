# wangrui2025.github.io

Permanent compatibility gateway for old personal-homepage links.

- Known homepage routes (`/`, `/zh/`, `/en/`, `/zh/cv/`, `/en/cv/`) forward directly to the matching route on `https://wangrui92.pages.dev`; unknown legacy homepage paths fall back to the canonical homepage entry.
- The real homepage source is maintained privately in `mykcs/personal-homepage`; the current canonical serving host is `https://wangrui92.pages.dev`.
- Project sites such as `/osa/`, `/GDKVM/`, and `/sprites-gallery/` are owned by their own repositories and are not copied here.

Development and CI/hosting rationale: [Dev folder](docs/dev/README.md). Product intent: [Wish folder](docs/wish/README.md).
