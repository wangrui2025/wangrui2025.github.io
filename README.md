# wangrui2025.github.io

Permanent compatibility gateway for old personal-homepage links.

- Known homepage routes (`/`, `/zh/`, `/en/`, `/zh/cv/`, `/en/cv/`) forward to the matching route on `https://mykcs.github.io`; unknown legacy paths fall back to the stable homepage entry.
- The real homepage source is maintained in `mykcs/mykcs.github.io`.
- Project sites such as `/osa/`, `/GDKVM/`, and `/sprites-gallery/` are owned by their own repositories and are not copied here.
